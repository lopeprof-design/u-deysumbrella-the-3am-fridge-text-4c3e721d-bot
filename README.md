The one line a smart fridge texts its owner at 3am: a 109-character message about a 2am burrito, a judgmental middle shelf, and a microwave that can't keep a secret. A comedy judge reads entries two at a time and the funniest line takes the $2 reward.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` — the same bytes on every run.
